# Fundamentos da POO (Programação Orientada a Objetos)

## Origem da Programação Orientada a Objetos

A Programação Orientada a Objetos (POO) surgiu com o objetivo de representar elementos do mundo real dentro de sistemas computacionais. Esses elementos são chamados de **objetos**, que possuem características (atributos) e comportamentos (métodos).

A evolução das linguagens de programação passou por diferentes etapas até chegar à POO:

- **Década de 1950:** surgiram as linguagens de baixo nível, como o Assembly, muito próximas da linguagem de máquina.
- **Por volta de 1955:** surgiram as linguagens procedurais/lineares, como a linguagem C, focadas na execução sequencial de instruções.
- **Década de 1960:** Edsger Dijkstra criticou o uso excessivo do comando `goto`, propondo o conceito de programação estruturada. Com isso, passaram a ser utilizadas estruturas de repetição, decisão e organização lógica do código, reduzindo a necessidade de desvios descontrolados.
- Nesse contexto também surgiu a linguagem **ALGOL (ALGOrithmic Language)**, importante para a evolução das linguagens estruturadas.
- **Por volta de 1965:** surgiram as linguagens modulares, trazendo maior separação e organização do código.
- **Na década de 1970:** Kristen Nygaard e outros pesquisadores introduziram o paradigma da Programação Orientada a Objetos, focado na modelagem de entidades do mundo real por meio de objetos.

A POO trouxe conceitos importantes como:
- Classes
- Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração

## OOAD

OOAD significa **Object-Oriented Analysis and Design** (Análise e Projeto Orientado a Objetos).

Esse conceito envolve o processo de analisar problemas e projetar sistemas utilizando os princípios da orientação a objetos.

Junto com o OOAD, surgiu também a **UML (Unified Modeling Language)**, uma linguagem de modelagem utilizada para representar graficamente sistemas orientados a objetos, por meio de diagramas como:

- Diagrama de Classes
- Diagrama de Casos de Uso
- Diagrama de Sequência
- Diagrama de Atividades
- Entre outros.
